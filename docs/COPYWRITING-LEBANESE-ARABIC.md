# Copywriting Guide — Lebanese Arabic DTC

## Voice

Warm, clear, confident, practical, Lebanese-friendly. Speak like a serious Lebanese brand, not a random ad page.

Use:

- Clean Lebanese Arabic mixed with standard Arabic where useful.
- Gender-neutral copy unless the product is clearly female-focused.
- Benefit-first language.
- Emotion first, proof immediately after.

Avoid:

- Gulf/Saudi phrasing: "تقدرين", "جوالك", "يوصل لك", "أضيفيه".
- Heavy slang that makes the brand feel cheap.
- Medical/beauty claims without evidence.
- Fake urgency.
- "أرخص سعر".

## Core Formula

For each product section:

1. Pain: "المشكلة اللي بتصير معك كل يوم".
2. Desire: "كيف بدك نهارك يصير".
3. Mechanism: "ليش المنتج بيساعد".
4. Proof: "صور، مواد، تجارب، مقارنة".
5. CTA: "اختار العرض وضيفه عالسلة".

## Hero Copy Template

```text
[نتيجة مرغوبة] بلا [ألم/تعقيد]

[سطر يشرح المنتج بوضوح] — مختار بعناية من سوق الشام ليناسب الاستخدام اليومي بلبنان.

★★★★★ 4.8/5
تقييمات العملاء تُضاف هنا بعد أول دفعة طلبات

[CTA] اختار العرض وضيفه عالسلة
الدفع عند الاستلام · بلا دفع مسبق · تأكيد قبل التجهيز
```

## Pain Language Examples

- "تعبت من منتجات شكلها حلو بالإعلان وبالواقع ما بتفيد؟"
- "كل مرة بتقول بسيطة، وبالآخر بتضيع وقتك وراحتك."
- "المشكلة مش بس بالمنتج، المشكلة بمتجر ما بيشرح لك شو عم تشتري."
- "بدك شي واضح، مرتب، وبيوصلك بلا مخاطرة دفع مسبق."

## Premium Framing

Use:

- "مختار بعناية"
- "عرض مرتب"
- "تفاصيل واضحة"
- "مناسب للاستخدام اليومي"
- "تجربة طلب مريحة"
- "بيستاهل سعره"

Avoid:

- "رخيص"
- "أرخص سعر"
- "نفس علي إكسبريس"
- "دروبشيبنغ"

## Proof Language

Use accurate proof framing:

- "منوضح لك المواد والاستخدام قبل الطلب."
- "صور المنتج الفعلية تُضاف هنا."
- "مقارنة بتوضح الفرق بين منتج عشوائي وعرض منسّق."
- "كل ادعاء بالصفحة لازم يكون معه صورة، تجربة، أو مواصفة بتدعمه."

## CTA Library

- "اختار العرض"
- "ضيفه عالسلة"
- "كمّل الطلب"
- "ضيفه بسعر خاص"
- "شوف العروض"
- "راجع السلة"
- "أرسل الطلب للتأكيد"

## Checkout Copy

```text
بيانات بسيطة لتأكيد طلبك
ما في دفع الآن. منحتاج الاسم ورقم الموبايل لتأكيد الطلب وتجهيز التوصيل.
```

Validation:

```text
اكتب رقم موبايل لبناني صحيح، مثال: 03123456 أو 70123456
```

Trust:

```text
رقمك يُستخدم لتأكيد الطلب فقط. بلا رسائل تسويقية من الموقع.
```

## Thank-You Copy

```text
تم استلام طلبك بنجاح
راح نراجع الطلب ونتواصل معك للتأكيد قبل التجهيز.

خلي موبايلك قريب منك، لأن التأكيد السريع بيساعدنا نجهّز الطلب أسرع.
```

## Objection Handling

### "غالي"

```text
السعر مش بس للقطعة. هو للعرض كامل، الشرح الواضح، الدفع عند الاستلام، والتأكيد قبل التجهيز. منفضّل منتج واضح وقيمة مرتبة بدل قطعة عشوائية بلا شرح أو ضمان.
```

### "بخاف ما يناسبني"

```text
لهيك منوضح الاستخدام والمواصفات قبل الطلب، ومنأكد معك قبل التجهيز إذا المنتج بده توافق معيّن.
```

### "ما بثق بالدفع أونلاين"

```text
ما بتدفع هلأ. الطلب بيتأكد أولًا، والدفع عند الاستلام.
```

### "في استبدال؟"

```text
إذا وصلك المنتج تالف أو غير مطابق للوصف، عندك سياسة استبدال واضحة خلال الفترة المحددة في صفحة الاسترجاع.
```

## Review/UGC Placeholders

Do not invent real people. Use:

```text
تقييمات العملاء تظهر هنا بعد الإطلاق.
```

For internal mockups only:

```text
[مثال تصميمي — يستبدل بتقييم حقيقي]
```
